# 串行通讯
1. 通信的定义:在两个设备之间进行数据传输
    - 分类:并行通讯和串行通讯
2. 并行通讯:数据传输率快,但传输成本高,抗干扰能力差,占用引脚资源多
   - 适用距离: 通常较短,多用在板子内部
   - 传输特点:多条数据线同时传输多个比特
3. 串行通信:相比并行通讯的传输时间长,速度慢,多用在长距离和低速率的通信
   - 传输特点:是将数据分成一位一位的形式再一条传输线上逐个传输
   - 发送线
   - 接收线
   - 地线
4. 通信协议
   - 硬件层协议:规定了物理上的连线,传输的电平信号,传输的秩序等等
   - 软件层协议:规定了数据的打包方式,校验方式等.
5. 传输过程:以传输一个字母A为例.一帧完整的串行数据对应的波形一共有10位,起始位低电平,停止位高电平,中间是八个二进制数据,从左到右分别代表1238163264128,高电平对应的数字相加和,如果波特率是9600,那么意思就是1秒钟发送9600位的一个二进制数据,也就是1s/9600=100us,波特率越高,发送的数据量更多,时间间隔越小
6. 同步传输:
   - 需要RXD(承担发送和接收的任务\半双工)和TXD(用作时钟线)
   - 依赖公共时钟信号,收发双方严格同步
   - 传输单位是数据帧,连续传输
   - 传输效率高,不需要起止位
   - 硬件相对复杂,需要时钟线,且时钟信号易衰减,成本较高
7. 异步传输:
   - 需要RXD和TXD/全双工
   - 无公共时钟,依赖双方预设的波特率
   - 每次传输单个字节,间隔可任意
   - 传输效率低,需要起止位
   - 连线少,成本低
   - 起始位(0)+8位+结束位(1)
8. 校验方法:
   - 奇偶校验:统计1的个数,附加1位校验位,但要是同时有两位数据发生翻转则接收端无法发现错误
   - 累加和:将所有数据字节相加,取低八位
   - 1. 把所有数据加起来
   - 2. 取低八位,超过255的部分扔掉
   - 3. 把数据和校验码一起发出去
   - 4. 接收方重新加起来然后进行比较
   - 异或:做异或运算(同0,异1),与累加类似
   - 1. 把第一个字节和第二个字节异或
   - 2. 把结果和第三个字节异或
   - 3. 把数据和校验码一起发出去
   - 4. 接受放重新异或再进行比较
   - CRC校验:校验能力最强! 基于多项式模2除法计算余数(假设发送110,约定好的生成多项式是1011)
   - 1. 数据补0,把发送数据后补上多项式位数减1个的0
   - 2. 用补0后的数据110000去除以1011,先最高位对齐,然后进行异或运算
   - 3. 然后忽略前导0,一直进行这个运算,如果结果不够多项式长了那就将算出来的余数(余数位数必须严格等于除数的位数-1)(校验码)拼在原始数据后面,最后的结果就为110001
9.  传输方向:
   - 单工:数据只能沿一个方向传输
   - 半双工:数据传输可以沿两个方向,但需要分时进行
   - 全双工:数据可以同时进行双向传输
10. UART:
    - 功能:在发送数据时将并行数据转换成串行数据来传输,在接收数据时将接收到的串行数据转换成并行数据
    - 协议层:
    - 1. 通信协议(包括数据格式,传输速率(波特率)等)
    - 物理层:
    - 1. 接口类型,电平标准等
11. 波特率:在异步传输情况下表示串口通信的速率,每秒传输二进制数据用的位数,单位是bit/s


### 手册
1. sbuf缓冲器(体现了全双工通信的特点)
   - 1. 发送缓冲器
    - 特点:只写不读,一旦把数据写入,单片机硬件就会自动启动发送流程,把这串数据从TXD发出去,发完硬件自动置1,完成一次发送但发完以后必须手动写TI=0,否则会卡死
   - 2. 接收缓冲器
    - 特点:只读不写,但外部设备通过RXD给单片机发数据时,硬件会自动把收到的数据存到这里面,并把RI标志位置1,如果从中读取不及时,再次发送会把第一个字节覆盖掉,导致数据丢失(溢出错误)
2. 串行通信有四种工作方式,两种波特率可变,另外两种是固定的
3. 波特率是由内部定时器/计数器产生,软件则得需要cpu来执行
4. 串口有三种扩展用法
- 1. 通过外接芯片把1根线变成8根线,外接到一个移位寄存器,直接驱动8个LED灯
- 2. 也可以做并串转换,将外部八个按键的状态一次性读进来,再通过串口一位一位传给单片机
- 3. 用于扩展串行外设
5. 多机通信:一对多,第九位做数据标志
6. 两个特殊寄存器:SCON(串口控制寄存器) PCON(电源控制寄存器)
- SCON:可位寻址;SM0 SM1 SM2 REN|TB8 RB8 TI RI
- SM0 SM1
  - 1. 0 0 方式0,同步,波特率是机器频率(时钟周期是1/11.0592MHz,就是1/11.0592us,因为51单片机是12分频,所以再乘以12得出单片机1次的机器周期是1.085us),波特率的计算方式:fosc/12,RXD用作数据线,从低位开始发送
  - 2. 0 1 方式1,异步(10位),波特率由T1控制(T1的方式2),异步RXD作接收引脚(p3.0)
  - 3. 1 0 方式1,异步(11位,多一位校验位),但波特率固定,时钟频率/32或时钟频率/64
  - 4. 1 1 方式3,异步(11位),波特率由T1决定(T1的方式2),波特率的计算公式:2的smod次方/32*fosc/12(256-TH1),T1计算公式相同
- SM2
  - 1. 0 单机通信,方式2,3有效
  - 2. 1 多机通信
- REN(接收允许位)
  - 1. 1 允许接收
  - 2. 0 禁止
- TB8 RB8
  - 1. TB8 发送数据的第九位,若SM2=0,作奇偶标志位;若SM2=1,TB8=1表示前八位是地址信息,TB8=0表示前八位是数据信息,一律把数据信息丢弃
  - 2. RB8 接收数据的第九位,若SM2=0,作奇偶标志位;若SM2=1,RB8=1表示前八位是地址信息,RB8=0表示前八位是数据信息,一律把数据信息丢弃
  - 3. 如果比较地址帧历携带的那8位具体的地址数据正确的话,接收方把SM2=0
- TI RI
  - 1. TI:发送中断标志 当SUBF发完单片机给的8位数据后,TI=1;
  - 2. RI:接收中断标志 当SUBF存完8位数据后,R1=1;
